  Design Audit: Current State

  Typography

  - Fonts: None specified. The site relies entirely on Tailwind's default system
   font stack (ui-sans-serif, system-ui, -apple-system, Segoe UI, Roboto, 
  Helvetica Neue, Arial, sans-serif). No custom fonts loaded anywhere — no
  Google Fonts link in index.html, no @font-face in CSS, no Tailwind fontFamily
  extension.
  - Scale: text-5xl font-extrabold for all page headings (PROJECTS, BLOG,
  CONTACT), text-3xl font-bold for card titles, text-xl for subtitles, text-lg
  for body, text-sm for metadata. All uppercase on page titles.
  - Verdict: Generic system fonts with no typographic personality. The hierarchy
   exists but feels templated.

  Color System

  - Dark mode (default): bg-black text-white — pure black background, pure white
   text
  - Light mode: bg-white text-black — pure white background, pure black text
  - Accent palette: Entirely Tailwind's default blue scale:
    - blue-900/30 and blue-900/40 — card backgrounds, hover states, nav active
  states
    - blue-800 and blue-800/50 — buttons, tags, borders
    - blue-700 — button hover states
    - blue-600 — focus rings, spinner
    - blue-400 — icons, link text, accents
    - blue-200 — category badge text
  - Neutrals: gray-400 for body text, gray-500 for secondary text, gray-800 for
  borders
  - Theme color: #1e3a8a (blue-800) in meta tags
  - Verdict: Monochromatic blue-on-black. No secondary accent, no warmth, no
  personality. The blue tints at 30% opacity create a washed-out, low-contrast
  feel. No CSS variables — colors are hardcoded across every component.

  Spacing & Layout

  - Container: max-w-6xl mx-auto used everywhere (header, main, footer)
  - Main content: mt-16 p-4 pb-20 — 16-unit top margin (for sticky header),
  20-unit bottom padding (for fixed footer)
  - Section spacing: space-y-16 between sections, gap-16 between grid items
  - Grid patterns: grid-cols-1 lg:grid-cols-2 for HomePage, md:grid-cols-2 for
  projects, md:grid-cols-1 for blog, md:grid-cols-3 for project detail info
  - Verdict: Generous spacing (gap-16 is 4rem) but applied uniformly. No rhythm
  variation, no visual tension. Everything breathes the same amount.

  Component Styling Patterns

  - Cards (ProjectCard, BlogPostCard): bg-blue-900/30 p-6 rounded-lg shadow-md —
   identical styling for both. Hover: bg-blue-900/40. The entire card is wrapped
   in a <Link>.
  - Buttons: px-6 py-3 bg-blue-800 text-white rounded-md hover:bg-blue-700 — all
   buttons look identical.
  - Tags/Badges: px-3 py-1 bg-blue-800/50 text-sm rounded-full — methods tags
  and category badges are visually the same.
  - Form inputs: bg-blue-900/30 border border-blue-800/50 rounded-md —
  consistent but indistinct from cards.
  - Verdict: Every interactive element uses the same semi-transparent blue
  treatment. Cards, inputs, tags, and nav buttons are hard to distinguish from
  each other.

  Dark/Light Mode Implementation

  - Mechanism: React Context toggle adds/removes dark class on <html>, but
  components use inline ternary conditions (darkMode ? 'bg-black' : 'bg-white')
  instead of Tailwind's dark: variant.
  - Coverage: Only partially implemented — many components hardcode
  dark-mode-only colors (e.g., text-white in cards, text-gray-400 in body text,
  focus:ring-offset-black on all buttons). Light mode would look broken in
  several places.
  - Verdict: Light mode is an afterthought. The app was designed dark-first and
  the light mode adaptation is incomplete.

  Motion & Interaction

  - Transitions: transition-colors on almost everything (buttons, links, cards).
   Duration: Tailwind default (150ms).
  - One animation: The loading spinner uses animate-spin — that's the only
  animation in the entire app.
  - Hover effects: Card arrow gap increases (group-hover:gap-3), card background
   lightens slightly, text color changes to blue-400. All subtle.
  - No page transitions, no scroll effects, no entrance animations, no 
  micro-interactions.
  - Verdict: Motion is minimal to the point of feeling static. The
  transition-colors on everything creates a uniform, monotone interactive feel.

  Backgrounds & Visual Depth

  - No textures, gradients, patterns, or layering. Pure flat color backgrounds
  (solid black or white).
  - Shadow: Only shadow-md on cards and shadow-lg on the homepage image. No
  other depth cues.
  - Backdrop blur: backdrop-blur-sm on the header — the only transparency
  effect.
  - Verdict: Completely flat. No atmosphere, no visual richness.

  Icons

  - Library: Lucide React throughout (Search, Sun, Moon, ArrowLeft, ArrowRight,
  Home, Mail, Phone, MapPin, Calendar, Clock, Linkedin, Github, Twitter)
  - Sizing: Consistently w-5 h-5 or w-4 h-4
  - Verdict: Functional but decorative-only. No creative use of iconography.

  Images

  - Projects: All use via.placeholder.com URLs — placeholder rectangles
  - Verdict: No real visual content beyond the profile photo.
